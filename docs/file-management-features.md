# ファイル管理機能の検討メモ

記録日: 2026-10-28

ユーザーが実装を検討したい機能。候補の記録であり、実装の指示や確定仕様ではない。

- 新しいフォルダを作成する機能
- ファイルをリネームする機能
- フォルダ表記の末尾に `/` を付ける

操作方法や具体的な仕様、実装時期は未決定。

## 実装済み（2026-10-29）

- 保存済みファイルのタブを右クリックし、「ファイル名変更」から同じフォルダ内で名前を変更できる。
- 拡張子を含む名前を入力する。初期選択は拡張子を除く部分。同名のファイル・フォルダには上書きしない。
- 未保存の本文、編集位置、見出しの開閉状態を保持し、同じファイルを表示するタブ・子ウィンドウにも変更を反映する。
- 無題の原稿は保存操作で名前を指定する。シンボリックリンクのリネームは対象外。

### ファイラーからの名前変更

- ファイル行の右クリックに「ファイル名変更」、フォルダ行の右クリックに「フォルダ名変更」を表示する。項目にフォーカスして Shift+F10 でも表示できる。
- フォルダ名の変更では、配下を表示しているファイラー・原稿・プレビューのタブ、および子ウィンドウの参照先を更新する。
- 同名のファイルや空フォルダも上書きしない。プロジェクト直下自体の変更は不可。
