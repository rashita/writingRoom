# プロジェクト一覧の本棚デザイン案

記録日: 2026-11-05

次回以降の開発で参照するためのアイデアメモ。実装の指示や確定仕様ではない。

## ユーザーのアイデア

- プロジェクト一覧を、本の表紙が棚に並ぶような画面にする。
- 参考画像は、暗い背景に複数段の棚があり、各棚にシリーズ名と表紙が並ぶデザイン。執筆中の作品を本棚に置くような見せ方。
- 表紙の色が均一だと面白みがないため、プロジェクト名のハッシュ値からカラーを自動で指定する。
- 一つずつ色を設定しなくても、プロジェクトごとに異なる色味が付くことを狙う。

## 会話で挙がった補足案（アシスタント提案・未採用）

- タイトルと背景色だけでも表紙として成立させ、画像の用意を必須にしない。
- ハッシュ値を色相に割り当て、彩度・明度は落ち着いた範囲に絞る。ハッシュによる色の重複や近似はあり得る。
- ハッシュの別の部分から、無地・細い枠・帯などの装丁を選ぶ案もある。
- 棚に自由な名前を付け、テーマ・媒体・進行段階などでまとめる。
- 選択した本の文字数・最終更新日・直近の本文などを表示する。
- 表紙から原稿の見出しを「目次」として表示し、執筆箇所へ移動する。書籍全体の見出しの構想は [heading-features.md](heading-features.md) を参照。

## 今後の検討事項

- 改題するとハッシュ由来の色も変わる。名前から都度生成するか、最初に生成した色を保存して改題後も保つかは未決定。
- 表紙を眺める楽しさと、棚による整理のどちらに重心を置くか。
- 色の範囲、装丁の種類、棚の操作方法、具体的なレイアウト、実装時期は未決定。
