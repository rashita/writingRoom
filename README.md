# Writing Room

執筆に使う原稿・資料・ダッシュボードを、ひとつの作業室にまとめる macOS 向けデスクトップアプリです。

ローカルのフォルダをプロジェクトとして開き、テキストの編集や HTML ダッシュボードの閲覧をタブで行えます。原稿は通常のファイルとして保存するため、ほかのエディタや Git と組み合わせて使えます。

現在は開発中の試作版です。自動保存・未保存内容の復旧には対応していません。

## 主な機能

- フォルダ単位で原稿や資料を開くファイラーとタブ
- UTF-8 テキストの編集、文字数表示、文字サイズの変更
- HTML・CSS・JavaScript で作れるダッシュボード
- タブとステータスバーを隠す全集中モード
- 複数プロジェクトと、原稿を別窓で開く子ウィンドウ
- 最近使ったプロジェクトと、前回の作業タブの復元
- 原稿の差分を確認して、そのファイルだけをコミットする進捗記録（試作）

## 開発環境で起動する

macOS 上で Node.js と npm、Rust と Cargo、Xcode Command Line Tools が必要です。

```sh
git clone https://github.com/rashita/writingRoom.git
cd writingRoom
npm ci
npm run dev
```

### アプリをビルドする

```sh
npm run build
```

生成先は `src-tauri/target/release/bundle/macos/Writing Room.app` です。現在の設定では macOS の `.app` を生成します。署名・公証は設定していません。

## 基本的な使い方

1. ファイルメニューの「プロジェクトを開く…」（⌘O）からフォルダを選択します。直下に `.writingroom.json` を作成します。
2. 別のプロジェクトを開くと新しいメインウィンドウになります。
3. `index.html` があればダッシュボードとして表示します。別名のHTMLも「HTMLを選ぶ…」から選択できます。index.htmlがない場合はフォルダ内のHTMLを名前順で検出します。
4. HTMLがなければ作成するか確認します。「作成しない」は設定に記録し、次回は確認・表示しません。ファイラーの「ダッシュボード」「HTMLを選ぶ…」から後で追加できます。
5. ファイラーからフォルダ、HTML、UTF-8テキストをタブで開きます。「別窓」でテキストの子ウィンドウを開けます。
6. テキストはファイルメニューの「保存」または ⌘S で保存します。テキストタブを右クリックすると「子ウィンドウで開く」を選択できます。同じファイルの編集内容はアプリ内で共有されます。メインウィンドウを閉じると子ウィンドウも閉じます。未保存の編集があれば確認します。

### HTML ダッシュボード

サンプルとして [dashboard.html](dashboard.html) を同梱しています。

ダッシュボードタブを右クリックして「ソースを編集」を選ぶとHTMLの編集タブを開けます。

HTMLは通常のHTML・CSS・JavaScriptを記述できます。相対パスの画像・CSS・スクリプトに対応し、相対リンクのフォルダやテキストをアプリで開きます。ダッシュボードはsandbox付きiframeで実行され、Tauriのファイル操作APIは公開していません。`localStorage` 等の同一オリジン機能は使用できません。

### プロジェクト設定

`.writingroom.json` に、フォルダごとのダッシュボードを記録します。

```json
{
  "version": 1,
  "dashboards": {
    "": "index.html",
    "資料": "overview.html",
    "原稿": null
  }
}
```

キーはプロジェクト直下からのフォルダ相対パスです。`null` はダッシュボードを表示しない指定です。

## 全集中モード

切り替え時はタブとステータスバーが約200msで薄くなりながら上下へ退き、本文領域が広がります。解除時は逆の動きです。macOSで「視差効果を減らす」が有効な場合は即時に切り替えます。

テキストタブを表示中に ⌘⌥F（Command + Option + F）または「表示 → 全集中モード」で切り替えます。タブとステータスバーを隠し、本文に集中できます。同じショートカットまたは Esc で通常表示に戻ります。日本語変換中の Esc は変換操作を優先します。本文の編集位置を保ったまま切り替え、⌘S で保存できます。ファイラーやHTML表示には適用せず、別の種類のタブに切り替えると解除します。モードはウィンドウごとに独立し、次回起動時には通常表示に戻ります。全画面表示とは独立しています。

## 最近使ったプロジェクト

入り口ページのタブ領域に、最近開いたプロジェクトを新しい順で最大20件表示します。クリックするとそのウィンドウで開き、作業タブへ切り替わります。ホバーでフルパスを確認できます。右クリックメニューで「別ウィンドウで開く」「履歴から外す」を選べます。履歴から外してもプロジェクトのファイルは変わりません。

作業中はファイルメニューの「最近使ったプロジェクト」から別のプロジェクトを開けます。フォルダが移動・削除されても履歴は保持し、見つからない旨を表示します。履歴はアプリのデータディレクトリ内の `recent-projects.json` に保存し、次回起動時も表示します。

## タブの復元

アプリ起動時はウェルカムページを表示します。最近使ったプロジェクトや「プロジェクトを開く…」から開くと、そのプロジェクトの最後のタブの種類・順序・選択状態を復元します。全タブを閉じた状態も記憶します。

前回の終了時に開いていたプロジェクトがあれば、ウェルカムページに「前回の作業を再開」を表示し、クリックすると前回のプロジェクトウィンドウとタブをまとめて復元します。その起動中に別のプロジェクトを開いても、再開対象は前回終了時の状態を維持します。既に開いているプロジェクトは追加で開かず、そのウィンドウにフォーカスします。「前回の作業を再開」は起動ごとに一度利用できます。ウェルカムページだけを表示して終了しても、前回の作業状態は保持します。

作業中は「ファイル → ウェルカムページを開く」でウェルカムページを開けます。既に表示している場合はそのウィンドウに戻ります。明示的に閉じたプロジェクトウィンドウは次回起動時の再開対象から外しますが、手動でプロジェクトを開いたときのタブ復元には影響しません。

状態はアプリのデータディレクトリ内の `workspace-state.json` に保存します。プロジェクトの設定 `.writingroom.json` とは分けて管理し、原稿の本文は含めません。未保存の編集があれば従来どおり終了確認を表示し、復元時にはディスク上の内容を読み込みます。子ウィンドウ、ウィンドウ位置、カーソル位置は復元対象外です。移動・削除などで復元できない対象はスキップして通知します。プロジェクトは絶対パスで識別するため、フォルダを移動すると以前のタブ状態は引き継がれません。


## 文字サイズ

テキストタブを表示中に「表示」メニューから文字を大きくする（⌘=、⌘+も使用可）、小さくする（⌘-）、標準に戻す（⌘0）を選べます。12〜32pxの範囲で1pxずつ変更し、標準は16pxです。全集中モードでも操作できます。

サイズはすべてのテキストタブ・別窓で共有し、アプリのデータディレクトリ内の `editor-preferences.json` に保存します。再起動後も維持します。行間は文字サイズの1.9倍で、本文幅は従来どおりです。

## Git による進捗記録（試作）

Gitで追跡済みの原稿を編集タブで開き、「履歴 → 進捗を記録…」（⌘K）を選びます。未保存なら保存を確認し、最新のcommitからの差分を表示します。メッセージを入力して「記録する」を押すと、この原稿1件だけをcommitします。他のファイルのステージ済み変更は含めません。Gitとリポジトリ、既存のcommit、Gitのユーザー設定が必要です。新規ファイルの登録やpushはターミナルで行ってください。

確認後に原稿やHEADが変わった場合は停止します。記録に失敗したときは入力画面にGitのエラーを表示します。

## 現在の制約

- UTF-8のテキスト編集（10 MiBまで）。Markdownはソースを編集します。
- ファイラーは一覧・フォルダ移動・ファイルを開く操作に対応しています。新規原稿作成、削除、名前変更、ドラッグ操作は今後の拡張対象です。
- 外部でファイルが変更された場合、保存を停止して上書きを防ぎます。編集内容をコピーして保管した後、プロジェクトを閉じて開き直してください。
- 原稿の自動保存、未保存内容の復旧、外部変更の自動取り込みは未実装です。
- ダッシュボードのファイルを保存した後は、そのタブを再選択すると表示が更新されます。

## 開発

Tauri 2 と Rust、バニラ JavaScript / CSS / HTML で構成しています。フロントエンドのフレームワーク・バンドラー・エディタライブラリは使用していません。ネイティブダイアログには Tauri 公式の dialog プラグインを使用しています。

```text
src/                    フロントエンド
src-tauri/src/          Rust のアプリ処理
src-tauri/capabilities/ Tauri の権限設定
src-tauri/icons/        アプリアイコンと原画像
tests/                  JavaScript のテスト
dashboard.html          ダッシュボードのサンプル
```

### 検証コマンド

```sh
npm run check
npm test
```

`npm run check` は `src/app.js` の構文を確認します。`npm test` はタブ復元・全集中モード・文字数表示の JavaScript テストと、Rust のテストを実行します。

依存関係の再現性を保つため、`package-lock.json` と `src-tauri/Cargo.lock` を管理対象に含めています。

### 開発者ツール

「表示」→「開発者ツールの表示／非表示」（⌘⌥I）で、現在のウィンドウのWeb Inspectorを開閉できます。ビルド済みのMacアプリでも使用できます。ElementsでHTML・CSS、ConsoleでJavaScriptの実行やエラーを確認できます。ダッシュボードはiframe内にあります。検証ツールで変更したCSSは一時的なので、残したい変更はHTMLやCSSのファイルに保存してください。

Tauriのdevtools機能はmacOSで非公開APIを利用するため、App Store向けに配布する際にはこの機能を無効化する必要があります。
